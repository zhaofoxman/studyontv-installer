📺 StudyOnTV 一键安装助手 v…

先学再看 · 在这台电脑上点几下，就能把 StudyOnTV 装到家里电视上，再用家长手机管理。
原理（来自官方安装文档）：adb connect 电视IP:5555 → adb install -r TV版APK → 自动打开应用 → 家长打开 http://电视IP:8099/admin/

第 0 步 · 准备 adb（只需一次）

本助手通过 adb 给电视装应用。如果上方徽章显示「ADB：未找到」，请下载 Google 官方 platform-tools， 解压后把 adb.exe（Mac 是 adb）连同 platform-tools 文件夹放到本程序同一个文件夹里，然后刷新本页。Windows 10 以上和 macOS 都自带下载用的 curl，不用另装。

第 1 步 · 在电视上打开 ADB 调试

① 打开开发者选项
设置 → 关于 / 关于本机 → 连点「版本号 / 内部版本号」7 次 → 返回上一级，出现「开发者选项」。
② 打开调试开关
开发者选项 → 打开 USB 调试，再打开 网络调试 / ADB over network（无线安装必须开这个）。
③ 记下电视 IP
设置 → 网络 / 关于，找类似 192.168.1.100 的地址。电视和这台电脑要连同一个 WiFi。
④ 第一次连接时点「允许」
电脑连过去时电视会弹「允许 USB / 网络调试」，一定要点确定，否则状态会一直是 unauthorized。

各品牌开 ADB 的位置

品牌路径
小米 / Redmi设置 → 关于 → 连点「产品型号」→ 开发者选项
TCL / 雷鸟设置 → 关于 → 本机信息 → 遥控器按「上 下 左 右」→ 底部「更多」→ ADB
索尼设置 → 设备偏好设置 → 关于 → 连点「内部版本号」7 次
海信 / Vidda关于页面开开发者选项，部分型号有专门菜单
创维 / 酷开关于页面或开发者菜单
康佳 / 长虹按具体型号找开发者选项
OPPO设置 → 系统 → 关于本机 → 设备型号 + 按键组合

前提：电视须是 Android 5.0+。鸿蒙 NEXT / 三星 Tizen / LG webOS 暂不支持。 Android 11+ 若只有「无线调试配对码」，请用下方「手动配对」：电视显示配对地址和 6 位码，填进来点配对，成功后电视无线调试页还会显示一个连接端口，扫描时把该端口填到「附加端口」里。

第 3 步 · 扫描局域网电视，一键安装

扫描端口 5555（ADB）和 8099（已装 StudyOnTV 的管理页），约几十秒。

还没有扫描结果。先在电视上打开网络调试，再点「动态扫描」。

第 4 步 · 装好后在电视上完成首次设置

① 设置管理密码
首次打开先设密码，扫码面板和接口都要用它验证，别告诉孩子。
② 按需开权限
悬浮窗 / 使用情况访问 / 自启动建议开；无障碍、防卸载可选，不开也能学习和管理题库。
③ 家长手机管理
手机和电视同一 WiFi，扫电视上的二维码，或浏览器打开管理页输入密码，即可改规则、管题库、批改主观题。
④ 关掉 ADB 调试
全部装完后，回电视开发者选项关掉调试，减少局域网暴露。

装不上？对照表

现象处理
扫描不到电视电视没开网络调试 / 不在同一 WiFi / 路由器开了 AP 隔离；或端口不是 5555（见配对说明）
状态 unauthorized去电视屏幕上点「允许调试」弹窗，再重新连接/安装
adb connect 拒绝 / 超时没开网络调试或端口不对，回第 1 步检查
「应用未安装」/ 解析包错误系统低于 Android 5.0，或下载的不是 TV 版 APK
装上闪退电视 WebView 版本过老，把品牌型号反馈到项目 Issues
管理页打不开先在电视上打开应用完成首次设置（设密码），且手机/电脑与电视同一局域网
